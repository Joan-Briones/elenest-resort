Step A — Fix Supabase Site URL (fixes —site url is improperly formatted—)

  1. Open Supabase ? Authentication ? URL Configuration
  2. Set Site URL to exactly this (not elenest://):
http://localhost/Elenest_Resort/html/

Redirect URLs must include:

http://localhost/Elenest_Resort/html/auth-callback.html elenest://auth/callback

Click Save.

Step B — Paste Google Client ID into the website

  1. Google Cloud ? Clients ? your Web application
  2. Copy Client ID (ends with .apps.googleusercontent.com)
  3. Open js/supabase-config.js in Cursor
  4. Put it here:
googleClientId: "YOUR_CLIENT_ID_HERE",

Also in that Web client:

  • Authorized JavaScript origins: http://localhost
  • Authorized redirect URIs: https://wstgqfcdpfifkqyrclkx.supabase.co/auth/v1/callback

Step C — Supabase Google provider

  1. Authentication ? Providers ? Google ? Enable
  2. Paste the same Client ID + Client Secret ? Save
